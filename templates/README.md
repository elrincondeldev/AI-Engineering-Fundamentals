# Templates

Professional documents you will use in the labs and the [capstone](../capstone/README.md). Copy a
template into your fork, fill it in and keep it next to your code.

| Template | Use it when | Example in the course |
|---|---|---|
| [Design doc](design-doc.md) | Before building a system: goals, design, alternatives, evaluation plan | Capstone proposal |
| [ADR](adr.md) | You make one important, hard-to-reverse decision | BM25 vs hybrid search; RAG vs fine-tuning |
| [Model card](model-card.md) | You ship a model or an LLM system | The support chatbot or a LoRA adapter |
| [Runbook](runbook.md) | Someone else will operate what you built | The playground gateway or the local model server |
| [Postmortem](postmortem.md) | Something went wrong and you want to learn from it | The bot quoted the superseded returns policy |
